# SiPath reference

Generated by `python3 -m sipath docs` from the declarations in `sipath/schema.py`
(design file) and `sipath/params.py` (step parameters); do not edit by hand.
A design file is checked against these before anything runs: unknown keys,
wrong types, values not allowed and missing required keys are errors.

## Design file

YAML or JSON; relative paths are relative to the file. Keys not listed are errors.

### top level

|---|---|---|---|
| `name` | str | yes | run and report name |

| `mode` | str | yes | macro: soft macro from floorplan_def; die: pad ring, die, macros (one of: macro, die) |
| `pdk` | str | yes | PDK description name (sipath/pdks) or path |
| `description` | str |  | free text |

| `rtl_parameters` | dict |  | top-level numeric elaboration parameters, applied by the selected frontend |

| `analog_shield` | list[str] |  | analog nets with grounded shield wires on both sides (route_analog) |

| `extra_lefs` | list[path] |  | more LEFs (black boxes, pads) |

| `is_core` | bool |  | the design is a chip core (routing to the PDK's top layer); false: embedded macro |
| `min_route_layer` | str |  | lowest routing layer; default: the PDK's |

| `pdn` | object |  | power grid; unset fields take the PDK's |
| `groups` | list[object] |  | hierarchy groups (fences, clusters) |
| `datapaths` | list[object] |  | structured placement |
| `clock_ports` | list[str] |  | clock ports (CTS nets); default: the ports of the SDC's create_clock commands, else clk |
| `clock_nets` | list[str] |  | explicit CTS nets |
| `keepouts` | list[box] |  | boxes the macro autoplacer avoids (um) |
| `macro_channel` | number |  | space between facing macros (um) |
| `macro_pin_clearance` | number |  | space in front of macro edges with signal pins (um) |

| `layer_adjustments` | dict |  | layer -> global-route capacity reduction (over the PDK's) |

| `allow_excluded` | list[str] |  | PDK-excluded cells used on purpose (waivers) |

| `auto_blackbox` | bool |  | macros without lib get a black-box Liberty model written from their LEF (off by default; a macro's own auto_blackbox overrides) |

| `harness_options` | dict |  | harness settings, e.g. {core_region: [x0, y0, x1, y1]} (um): standard-cell rows only there (a wrapper is mostly empty), plus a channel of rows (pin_channel_rows, default 2) to each used pin farther than pin_reach um (default 300) from it, for repair to buffer the pin's net next to the pin (pin_channels: false: none) |
| `supply_names` | dict |  | PDK core supply net -> its name in this design, e.g. {VDD: vccd1, VSS: vssd1} (standard-cell supplies, PDN, macro and pad supply maps, signoff) |
| `plugins` | list[str] |  | Python modules imported before this file is checked; they register steps, scores, signoff checks, harnesses and extension keys (sipath.registry) |
| `extensions` | dict |  | plugin namespace -> its settings, checked against the keys the plugin registered |
| `config` | object |  | run configuration (also SIPATH_* environment, --config) |
| `inputs` | object |  | generated inputs |
| `flow` | list[object] |  | steps in order; default: the standard chain |

## Step parameters

Set per attempt in `variants` (design file `flow:` or MCP `run_step`), or as defaults in a design file's or PDK description's `step_defaults: {step: {param: value}}`. Resolution: variant, then design, then PDK, then the default below.

### synth

| parameter | type | default | allowed | description |
|---|---|---|---|---|
| `abc` | str | – | area_classic, area_lut6, area_map, area_max, balanced_resyn, balanced_resyn2x, delay_aggressive, delay_choice_deep, delay_choice_deep_bb, delay_choice_deep_v3, delay_choice_deep_v4, delay_iter_heavy, delay_map, delay_map_resyn, delay_syn2, delay_triple, orfs_area, orfs_speed, speed_sizing, yosys_default, area, delay, speed | one ABC recipe instead of abc_sweep (sipath/synth_recipes: 18 measured in shalan/synth_flow, plus area_map and speed_sizing; aliases delay, area, speed) |
| `abc_sweep` | str | auto |  | recipes mapped in this attempt, the netlist picked by synth_select (least area meeting timing, else synth_fallback's pick): auto (the delay set plus area_map), delay, area, balanced (synth_flow's top 5 each), off (delay_map_resyn alone), or recipe names separated by commas (one string, not a list) |
| `synth_fallback` | str | best_slack | knee, best_slack, least_area | when no recipe meets timing at synthesis: best_slack (the fastest netlist; measured best end to end, docs/synthesis.md), knee (of the slack/area front, else best slack) or least_area |
| `map_corner` | str | – |  | corner whose Liberty dfflibmap and ABC map with: a corner name, typical, or (default) the timing corner, the slow one (bench: 12/16 designs meet timing against 10 at typical) |
| `synth_abc` | bool | false |  | keep Yosys's generic ABC pass in synth (default: synth -noabc, as synth_flow; measured mixed: better on aes, worse on gcd8) |
| `abc_target` | str | none |  | ABC delay target ({D} in the recipe): none (measured best on most designs), period (the SDC clock), or a number of ps |
| `abc_period_ps` | float | – | 1.. | the period abc_target: period stands for; default: the SDC's first create_clock [ps] |
| `abc_wire_load` | bool | false |  | ABC sizing (buffer, upsize, dnsize, stime) with the Liberty's wire-load model (-c; built into delay_map and delay_map_resyn) |
| `abc_boundary` | bool | true |  | give ABC the driving cell and output load (the SDC's, else the PDK's boundary defaults for a macro) |
| `synth_opts` | list[str] |  |  | front-end options: booth, adder=kogge-stone|han-carlson|sklansky, noshare, nofsm, noalumacc, opt_dff_sat, opt_full |
| `keep_names` | bool | true |  | name registers after the wire they drive (acc[3]_reg) through flattening |
| `frontend` | str | auto | auto, yosys, slang | RTL reader: yosys (read_verilog -sv), slang (read_slang: full SystemVerilog; the image's Yosys must have it), auto (slang for .sv sources when available) |
| `retime` | bool | false |  | retime registers in generic synthesis (abc -dff, what synth -retime ran); flops with asynchronous set/reset are not moved |
| `verilator` | str | auto | auto, on, off | Verilator lint (--lint-only -Wall): auto (when Verilator is found: host, native tool or image), on (required), off; errors fail, warnings counted by code |
| `timing` | bool | true |  | estimate the netlist's setup slack (OpenSTA at timing_corner with the SDC and the Liberty's wire-load model): synth_wns_ns, synth_tns_ns, for scoring synthesis variants |
| `timing_corner` | str | – |  | corner of the estimate (default: the worst-setup corner of the PDK's optimize_corners, e.g. ss_max) |
| `lint` | bool | true |  | lint the RTL first (implicit nets, hierarchy, undriven / multiply driven nets, combinational loops are errors) |
| `lint_strict` | bool | false |  | fail on any lint warning (Yosys or Verilator) |
| `equiv` | str | bounded | bounded, off | check the netlist against the RTL: bounded (equal outputs for equiv_depth cycles from reset, every input sequence) or off |
| `equiv_depth` | int | 10 | 1.. | cycles from reset the equivalence covers |
| `equiv_reset` | str | – |  | reset port and active level, e.g. rst_n:0 (default: found, in any case, among rst_n, resetn, reset_n, rstn, nrst, rst_ni, presetn, hresetn, aresetn, arst_n (active 0), rst, reset, arst (active 1)) |
| `equiv_timeout` | int | 600 | 1.. | SAT time limit; reached: inconclusive (reported, not passed) [s] |
| `equiv_on_timeout` | str | warn | warn, fail, pass | when the equivalence check times out: warn (the step passes, the run's verification verdict is inconclusive), fail (the step fails), or pass (accepted: the verdict counts the check as passed and notes the timeout) |
| `port_buffers` | bool | true |  | buffer assignments between ports (off: a port-to-port assignment stays one net with two pins, e.g. a wrapper output tied to a frame loopback input) |

## Run configuration

Design file `config:`, a `--config` file, or the environment variable each key names (sipath.config; not always `SIPATH_<KEY>`). Later sources win: defaults, the `--config` file, the environment, the design file's `config:`.

| key | environment | type | description |
|---|---|---|---|
| `strict_reproducibility` | `SIPATH_STRICT_REPRODUCIBILITY` | bool | serialize attempts and include execution resources in resume fingerprints; does not guarantee tool determinism |
| `threads` | `SIPATH_THREADS` | int | the run's cores: one attempt's OpenROAD threads, shared among attempts running at once and among a signoff's concurrent checks (default: every core, as ORFS; two thirds of them on macOS, where Docker's VM shares the cores with the host) |
| `command_timeout` | `SIPATH_TIMEOUT` | number | seconds before a Tcl command is abandoned |
| `parallel_cap` | `SIPATH_PARALLEL_CAP` | int | attempts at once across a step (0: as asked) |
| `budget_s` | `SIPATH_BUDGET` | number | wall-time budget of a run in seconds (0: none): past it, running attempts stop with status budget; --resume continues |
| `step_budget_s` | `SIPATH_STEP_BUDGET` | number | a time box per step in seconds (0: none): attempts not finished stop (budget) and the step selects among those that finished |
| `max_attempts` | `SIPATH_MAX_ATTEMPTS` | int | most attempts a run starts (0: none); the rest end with status budget |
| `memory_gb` | `SIPATH_MEMORY_BUDGET` | number | memory budget in GB (0: none): fewer attempts at once when the step's recorded peak memory says they would not fit |
| `container_cpus` | `SIPATH_CPUS` | number | CPU limit per container |
| `container_memory` | `SIPATH_MEMORY` | str | memory limit per container (e.g. 8g) |
| `image` | `SIPATH_OPENROAD_IMAGE` | str | ORFS image (name@sha256:... pins it) |
| `placer_python` | `SIPATH_PLACER_PYTHON` | str | Python with PyTorch for the macros method cdlns (sipath setup-placer) |
| `magic_image` | `SIPATH_MAGIC_IMAGE` | str | image with Magic for the signoff checks magic_drc and xor (docker/magic) |
| `openroad_binary` | `SIPATH_OPENROAD_BINARY` | str | OpenROAD inside the image (default the ORFS path; openroad for an image with it on PATH) |
| `platform` | `SIPATH_PLATFORM` | str | image platform: linux/amd64, or linux/arm64 for a native arm64 image |
| `native_tools` | `SIPATH_NATIVE_TOOLS` | list[str] | tools run on the host instead of the image (klayout, yosys, magic): faster than emulation |
| `runtime` | `SIPATH_RUNTIME` | str | where OpenROAD, Yosys and KLayout run: auto ($SIPATH_OPENROAD, then openroad on PATH, then the locked tools unpacked by install-tools, else the locked image), native, or docker |
| `tools_root` | `SIPATH_TOOLS_ROOT` | str | the locked image's tools unpacked by sipath install-tools (default ~/.cache/sipath/orfs-root) |
| `tool_timeout` | `SIPATH_TOOL_TIMEOUT` | number | seconds one signoff tool run (KLayout DRC/LVS, Magic) may take |
| `require_digest` | `SIPATH_REQUIRE_DIGEST` | bool | refuse an image not pinned by digest (default on) |
| `precheck_image` | `SIPATH_PRECHECK_IMAGE` | str | image with ChipFoundry's cf-precheck and its tools (precheck step) |
| `require_pdk_release` | `SIPATH_REQUIRE_PDK` | bool | refuse an open_pdks tree whose release is not the locked one (default on) |
| `debug_failed` | `SIPATH_DEBUG_FAILED` | bool | write a debug checkpoint for a failed attempt |
| `log_level` | `SIPATH_LOG_LEVEL` | str | sipath logger level |
| `snapshots` | `SIPATH_SNAPSHOTS` | str | a layout picture after every step (_pictures/<attempt>.png, in the report): off, selected (each step's selected attempt) or all (every finished attempt) |
